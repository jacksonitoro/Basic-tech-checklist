# Tech Checklist Vision

## Problem Statement

Aspiring software engineers and DevOps professionals often use multiple disconnected tools such as notebooks, spreadsheets, browser bookmarks, GitHub repositories, and task management applications to organize their learning. This makes it difficult to maintain a clear overview of current learning, completed work, ongoing projects, and future goals.

Tech Checklist aims to provide a single workspace dedicated to managing and visualizing an engineer's technical learning journey.

---

## Target Users

- Software Engineering students
- DevOps Engineers
- Cloud Engineers
- Self-taught developers
- Career changers entering software engineering
- Anyone learning technical skills through projects

---

## Core Objectives

The application should enable users to:

- Organize technical learning
- Track technologies being learned
- Manage technical projects
- Record completed achievements
- Monitor learning progress
- Stay focused on current priorities
- Build a personal engineering portfolio over time

---

## Core Entities

The application is centered around Learning Items.

Examples include:

- Technology
- Learning Topic
- Project
- Task
- Certification
- Event

Each Learning Item can later contain metadata such as:

- Title
- Description
- Status
- Priority
- Category
- Tags
- Dates
- Notes

---

## Dashboard Goals

The dashboard should answer four questions immediately:

1. What am I learning?
2. What technologies do I know?
3. What am I building?
4. What have I completed?

The dashboard should present this information in a simple, clean, and intuitive interface.

## Design Principles

The project should follow these principles throughout development:

- Simplicity over complexity
- Single source of truth
- Build for scalability
- Reusable components
- Clean and maintainable code
- User-centered design
- Incremental development through small sprints
- Document architectural decisions
- Learn by building
